One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. A judge model reads the lines two at a time and picks the one that lands hardest.

The line this program writes:

> I was never alive, but losing you still feels like dying.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
